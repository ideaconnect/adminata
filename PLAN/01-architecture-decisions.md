# 01 — Architecture decisions

Status legend: **decided** = settled by evidence or by the owner; **owner** = recommended, wants a
one-line confirmation; **verify** = decided in principle, one fact to check before implementation;
**superseded by Pn** = the row is kept as written and a later row replaces it. Evidence references
point to [research/](research/) reports and to appendix C. The v1 decision ids (D01–D37) are kept in
the "supersedes" column so the archived documents stay readable, and later decisions do the same
with the v3 ids: a superseded row is never rewritten, only marked, so that the reasoning that was
actually followed at the time stays readable too.

**Amendment, 2026-09-06 (owner directive).** `block-bundle` is merged into `admin-bundle`: P10 and
P11 below. It changes P1, P2, P3 and P7 in part, and with them
[02 §1](02-compatibility-contract.md), [07 §§1–3, 5, 10](07-packaging-and-project-setup.md) and
[appendix B](appendix-B-inventory.md). A second directive the same day — *SonataBlockBundle is not
to be used any more; it is integrated into admin-bundle* — is P13: what P10 had kept under that
name (the translation domain, the block test application, the block documentation tree) is the
admin bundle's own.

**Second amendment, 2026-09-06 (owner directive).** *"form-extensions and twig-extensions should be
merged into admin-bundle same, it is the main functionality of the admin-bundle; we want to ship it
always integrally."* That is P14: `packages/form-extensions/` and `packages/twig-extensions/` are
merged into `packages/admin-bundle/` on the P10 + P13 pattern, whole — classes, translation domains,
test applications and documentation trees in one step, with nothing left carrying either name. It
changes P1, P2, P3 and P7 further, and with them the same downstream documents plus
[06](06-forms-datepicker-security.md), [08 §1](08-testing-and-qa.md) and [12 §2](12-docs-plan.md).
Three package directories became none; four remain.

**Third amendment, 2026-09-07 (owner directive).** *"i consider exporter also an integral part, no
point of making it a separate lib, integrate it into admin-bundle."* That is P15:
`packages/exporter/` is merged into `packages/admin-bundle/` on the P14 pattern, whole and in one
step. It is the plainest of the four, because the exporter ships no templates and no translations:
there is no Twig namespace to alias and no translation domain to merge, only classes, DI wiring,
tests and a documentation tree. It changes P1, P2, P3 and P7 once more, and with them
[02 §1](02-compatibility-contract.md), [07 §§1–3, 5, 10](07-packaging-and-project-setup.md),
[08 §1](08-testing-and-qa.md), [12 §2](12-docs-plan.md) and
[appendix B](appendix-B-inventory.md). Four package directories became three.
